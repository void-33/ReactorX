# ...Insert Project Title
Virtual Chemistry Lab is an interactive simulation app that allows users to explore, perform, and learn chemistry experiments in a safe virtual environment. Designed to make chemistry accessible, visual, and engaging without the need for physical labs.

# Features
- Lab Equipments Selection Sidebar
- Virtual Lab Canvas
- Visible Experimental Results
- Interactive UI and Design

# Setup and Installation
```bash
git clone https://github.com/void-33/TechSprint_Infinite
cd TechSprint_Infinite
npm install
npm run dev
```

# Tech Stack
- **Frontend:** HTML, CSS, JS, React, Next.js
- **Animation:** GSAP
