# 🧪 ReactorX – Industrial Plant and Emergency Response Simulation

> An immersive platform for mastering industrial safety across chemical, manufacturing, and processing facilities through interactive accident response scenarios

---

## What is ReactorX?

**ReactorX** transforms industrial safety training by creating realistic and risk-free simulations of diverse chemical and industrial operations. Step into the role of a safety engineer across multiple industrial environments from chemical manufacturing plants to petroleum refineries where you'll navigate high-stakes scenarios, detect critical failures and execute life-saving emergency protocols all within an engaging interface.

Whether you're a student exploring industrial processes or a professional honing safety skills across different sectors this platform bridges the gap between theory and real world application.

---

##  Why This Matters

Industrial chemical accidents pose serious risks to workers, communities and the environment. Our simulation platform helps users:

- **Build Intuition** – Understand complex chemical processes through hands on interaction
- **Train Safely** – Practice emergency response without real world consequences  
- **Develop Expertise** – Gain proficiency in accident detection and mitigation protocols
- **Raise Awareness** – Learn industry standard safety practices and preventive measures

---

##  Key Features

###  Realistic Industrial Environment
Interact with authentic industrial components across multiple sectors including storage tanks, high pressure pipelines, automated valves, heat exchangers, reactors, distillation columns, cooling systems and emergency response stations.

###  Dynamic Accident Scenarios
Experience real time simulations of industrial hazards including chemical leaks, pressure vessel failures, thermal runaway reactions, equipment malfunctions and fire scenarios that demand quick thinking and proper response protocols.

###  Interactive Controls
Activate safety mechanisms, shut down compromised systems, deploy protective equipment and coordinate worker evacuations through an intuitive interface.

###  Live Feedback & Visualization
Monitor real-time experimental results, chemical concentrations, temperature changes and system status through dynamic dashboards.

###  Smooth, Engaging UX
Enjoy fluid animations powered by GSAP and Framer Motion that bring the industrial environment to life while maintaining educational focus.

##  Quick Start

Get the simulation running locally in under a minute:

```bash
# Clone the repository
git clone https://github.com/void-33/TechSprint_Infinite.git

# Navigate to project directory
cd ReactorX

# Install dependencies
npm install

# Launch development server
npm run dev
```

Then open [http://localhost:9002](http://localhost:9002) in your browser to start exploring!
