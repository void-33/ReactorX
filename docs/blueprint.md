# **App Name**: ReactorX

## Core Features:

- Virtual Lab Environment: Interactive environment that mimics a real chemistry lab, with drag-and-drop functionality for apparatus and chemicals.
- Animated Lab Equipment: Visually appealing, animated simulations of lab equipment such as beakers, test tubes, flasks, burners, and droppers.
- Reagent Interactions: Realistic simulations of chemical reactions including liquid pouring, bubbling effects, color changes, and smoke/steam animations.
- Guided Experiments: Step-by-step experiment flow with animated transitions, tooltips, and clear instructions. A tool for providing guidance during experiments.
- Reagent Selection: Allow users to select specific reagents (like acids or bases) for each experiment.
- Experiment Completion Logic: Tracks steps and determine the conditions when an experiment has been performed succesfully. A tool to determine what the right moment for experiment success is.
- Save experiments: Ability to save performed experiments including setup and results.

## Style Guidelines:

- Primary color: Light teal (#A0CED9) to evoke cleanliness and a laboratory setting.
- Background color: Pale off-white (#F4F5F7) for a neutral backdrop that reduces eye strain during long sessions.
- Accent color: Soft lavender (#B2BEB5) for interactive elements and highlights, providing a subtle contrast.
- Body and headline font: 'Inter' sans-serif for a modern and easily readable interface.
- Use flat, minimalist icons for equipment and tools to maintain a clean, modern look.
- Dashboard layout with a central experiment area flanked by reagent and control panels.
- GSAP-style animations for realistic liquid movement and smooth transitions between experiment steps.
